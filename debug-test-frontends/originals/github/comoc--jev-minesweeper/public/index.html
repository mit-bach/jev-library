このデモの仕組み

1手ごとに、数字に接している未開封マスをすべて集め、マスごとに Noul 質問「Is the target cell a mine?」を作ります。質問にはそのマスに関係する手がかりだけを英語で載せ（例：D4: exactly 1 of these 2 hidden cells is a mine: D5, E5）、全問を1回のリクエストで送ります。Jev は各質問を独立に並列評価し、地雷である確率を返します。

「数字 − 周りの旗」のような算術は、渡す前にコードで済ませています（Jev は計算より読解と判断が得意なため）。「Jevへの渡し方」を「生の数字だけ」にすると、算術も Jev 任せになります。

Jev＋ソルバーでは、Jev が確信できる手（開く基準以下／旗の基準以上）だけを Jev に任せ、どのマスも確信できないときは厳密ソルバーに回します。答え合わせの数字は評価専用で、手の決定には使いません。
