# Client SDKs

Install a TypeSafe client SDK and use typed questions and answers in your application.

Our client SDKs provide typed questions and answers for the TypeSafe API and handle retries automatically with their default retry policy.Choose a client SDK for installation instructions, examples, and API details.[PythonInstall the Python client SDK and make your first request.](sdk/python.md)[JavaScript / TypeScriptInstall the JavaScript client SDK and make your first typed request.](sdk/javascript.md)You can also call the[HTTP API](api.md)directly from any language.
