# Jev debug and test shelf

Snapshot opened 2026-10-02. This directory is a separate collection from the 2026-10-01 source corpus one level up.

It holds projects a person can open while debugging and testing a system that uses Jev. The useful ones are playgrounds, request inspectors, local dashboards, browser-test loops that leave a report, and eval harnesses with fixtures. Ordinary Jev apps are not the point of this shelf.

Jev is TypeSafe's System One model. It answers typed questions. It does not render the page and it does not replace the coding model. Official calls in the 2026-10-01 docs snapshot go to `POST https://api.typesafe.ai/v1/systemone`.
